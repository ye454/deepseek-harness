# Task Rules

- Preserve unrelated tracked and untracked work; do not clean generated artifacts.
- Scope implementation to the merged `work-console` consolidation and its direct build/test contracts.
- Do not weaken TypeScript or test gates with global skips, broad casts, or disabled tests.
- Do not commit secrets, credentials, or generated build output.
- Push only the intentional fix commit to the existing `origin` remote and current feature branch.
